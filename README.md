**Полный перенос ещё не завершён. Это исходники разрабатываемого порта, не готовый релиз.**

Основная платформа: **Minecraft Java 26.2 · NeoForge 26.2.0.81 · Java 25**.

## Сборка

Установить JDK 25 (например, Temurin), задать `JAVA_HOME` на его директорию.
Gradle Wrapper скачает закреплённые зависимости при первом запуске.

```powershell
.\gradlew.bat build
.\gradlew.bat :neoforge-26.2:runGameTestServer
.\gradlew.bat :neoforge-26.2:runOreWorldTestServer
.\gradlew.bat :neoforge-26.2:runChemistryTestServer
.\gradlew.bat :neoforge-26.2:runClient
```

Linux/macOS: использовать `./gradlew` с теми же аргументами.
Первый запуск требует интернета и времени на подготовку Minecraft.
Локальная сборка появляется в
`platforms/neoforge-26.2/build/libs/techguns-26.2-neoforge-0.1.0-dev.jar`.

На этом рабочем месте JDK также находится в игнорируемой Git папке `.tools/jdk25`.
Она не является частью репозитория: после клонирования установить собственный JDK 25.
Для использования локального JDK без настройки окружения в этом проекте:
`powershell -File tools/dev.ps1 build` (вместо `build` можно указать задачу запуска).

## Что можно попробовать

В новой тестовой игре с командами:

```mcfunction
/give @s techguns:revolver
/give @s techguns:pistolrounds 16
```

Предметы доступны во вкладке Techguns. Новое оружие пустое.
ЛКМ — выстрел; автоматическое оружие продолжает огонь при удержании. R — перезарядка.
Клавишу перезарядки можно изменить в настройках управления. Смена оружия отменяет
перезарядку. ПКМ включает прицеливание у образцов с оптикой; повторное нажатие
выключает его. R также выключает прицеливание. Масштаб FOV и изменение точности
берутся из оригинала. HUD показывает боезапас и ход перезарядки; полоса предмета
дублирует боезапас. Характеристики автоматически извлекаются из оригинала.

| Оружие | Боеприпас | Ёмкость | Зарядка |
|---|---|---:|---|
| Ручная пушка | `stonebullets` | 1 | Один предмет |
| Обрез | `shotgunrounds` | 2 | Поштучно; 8 снарядов за выстрел |
| Револьвер | `pistolrounds` | 6 | Один предмет заряжает барабан |
| Золотой револьвер | `pistolrounds` | 6 | Один предмет заряжает барабан |
| Thompson | `smgmagazine` | 20 | Магазин; возвращает пустой и целые оставшиеся пачки патронов |
| Болтовая винтовка | `riflerounds` | 6 | Один предмет заряжает винтовку |
| Боевой дробовик | `shotgunrounds` | 8 | Поштучно; 8 снарядов за выстрел |
| Пистолет | `pistolmagazine` | 18 | Магазин |
| AK-47 | `assaultriflemagazine` | 30 | Магазин |
| M4 | `assaultriflemagazine` | 30 | Магазин |
| M4 Infiltrator | `assaultriflemagazine` | 30 | Магазин |
| LMG | `lmgmagazine` | 100 | Магазин |
| MAC-10 | `smgmagazine` | 32 | Магазин |
| AS50 | `as50magazine` | 10 | Магазин |
| AUG | `assaultriflemagazine` | 30 | Магазин |
| SCAR | `assaultriflemagazine` | 20 | Магазин |
| Vector | `smgmagazine` | 25 | Магазин |

При замене магазина возвращаются пустой магазин и целые неиспользованные пачки.
Клиентская обработка клавиш и HUD скомпилированы; визуальная проверка ещё не завершена.
Статические модели содержат 493 исходные детали; анимации, отдача, прицельные сетки
и варианты патронов ещё переносятся.

Перенесены 77 исходных рецептов верстака. Из обычных материалов можно собрать
ручную пушку и её патроны, револьвер, обрез и пустой Thompson. Другие патроны
и оружие требуют свинца, стали, пластика и продукции станков. Свинец теперь
добывается из руды, сталь выплавляется в домне, пластик производится через лабораторию;
титан и более сложные производственные цепочки ещё переносятся.
Ammo Press уже производит четыре базовых вида боеприпасов;
наличие рецепта не означает доступность всей цепочки добычи в выживании.
Крафт с заполненным магазином даёт заряженное оружие, с пустым — разряженное.
Позолота револьвера сохраняет патроны и имя. Рецепты улучшения M4 до Infiltrator
пока исключены из-за неоднозначности исходных правил переноса состояния.
Использовать новые тестовые миры; импорт сохранений 1.12.2 не реализован.

`techguns:ammo_press` принимает свинец/сталь, медь/железо/олово/бронзу и порох.
Рабочий цикл — 100 тиков, 500 FE на партию; до семи улучшений увеличивают её размер.
Проверены воронки, сохранение операции, редстоун и доступ владельца. В серверном
`config/techguns-server.toml` сохранена исходная опция `machinesNeedNoPower = true`
для игры без внешнего генератора. По умолчанию питание требуется. Анимация пресса
и визуальная приёмка его меню ещё не завершены.

`techguns:metal_press` выполняет все 19 исходных производственных рецептов: пластины,
провода, механические детали и заготовки боеприпасов. Есть авторазделение одинакового
сырья, общий код сохранения/питания и работа через воронки. Обычный цикл стоит 2000 FE;
пакетные улучшения сохраняют фактический квадратичный расход оригинала. Неподвижная
модель перенесена, анимация и визуальная приёмка остаются в плане. Производство
особых патронов уже добавлено, их применение оружием ещё переносится.

`techguns:blast_furnace` выплавляет сталь из железа и угля/древесного угля,
обсидиановую сталь и бронзу по четырём исходным рецептам. У неё накопитель 40 000 FE,
фиксированный порядок входов и сохранение длинных операций. Проверена передача
готовой стали в Metal Press через воронку. Модель, звуки и частицы перенесены;
клиентская визуальная приёмка ещё не завершена.

Пять исходных руд генерируются в новых чанках Верхнего мира. Медная, оловянная
и свинцовая плавятся в обычной печи; лаборатория перерабатывает уран в yellowcake.
Обработка титана и обогащение урана ещё переносятся. Все 19 исходных рецептов печи
добавлены, включая переработку деталей и пластин. Генерацию каждого металла
можно отключить в `config/techguns-worldgen-server.toml`.

`techguns:chem_lab` выполняет 24 самостоятельных рецепта и семь условных вариантов
для дополнительных ингредиентов/жидкостей. Баки вмещают 8/16 вёдер; доступны
каучук, пластик, кислота, углеродные волокна, TGX и другие продукты. Проверены
вёдра, воронки, сохранение партий, переключение баков и исходные настройки топлива.
Анимация модели и радиационные эффекты произведённых лекарств ещё переносятся.

## Структура

| Директория | Назначение |
|---|---|
| `core` | Правила оружия и исходные каталоги без зависимости от Minecraft; unit tests |
| `platforms/neoforge-26.2` | Современный мод, предметы, пуля, ресурсы и GameTests |
| `legacy/1.12.2` | Сохранённые исходники и ресурсы оригинала; не компилируются новой сборкой |
| `content` | Воспроизводимый каталог исходников |
| `tools` | Проверка каталога и преобразование ресурсов |
| `docs` | План, статус и инструкции |

Для проверки каталога и исходных ресурсов нужен Python 3.10+ без сторонних библиотек:

```text
python tools/audit_legacy.py --check
python tools/generate_weapon_content.py --check
python -m unittest discover -s tools/tests -v
python tools/verify_resources.py
```
